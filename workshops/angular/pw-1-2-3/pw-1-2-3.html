Angular — MesProduits

Guide pratique de création d'une application Angular avec Bootstrap.

⚡ Mise en place du projet

0Save Your Time

1Créer un projet Angular nommé MesProduits.

2 Éditer le projet avec VS Code, créer un terminal et lancer le serveur intégré.

3 Tester votre travail : http://localhost:4200

4 Installer Bootstrap :

npm install bootstrap

5 Éditer le fichier angular.json.

6 Éditer le fichier app.html.

7 Ajouter bootstrap.bundle.min.js dans la rubrique scripts de angular.json.

8 Redémarrer le serveur :

q + Enter → ng serve

9 Tester les listes déroulantes.

📦 Composant Produits

10 Créer le composant Web produits.

11 Éditer app.routes.ts et ajouter la route « produits ».

12 Éditer app.html pour ajouter le lien vers le composant produits.

13 Importer RouterLink dans app.ts.

14 Tester le lien en cliquant sur « Home ».

➕ Ajouter un produit

15 Créer le composant add-produit.

17 Ajouter le lien vers add-produits dans app.html.

18 Ajouter /produits comme composant par défaut.

19 Aller sur http://localhost:4200/produits

📋 Gestion des produits

20 Dans la classe Produits, créer l'attribut produits comme tableau de produits.

21 Dans le constructeur, affecter des produits au tableau.

22 Afficher la liste des produits dans produits.html.

23 Importer CommonModule dans produits.ts pour utiliser *ngFor.

🧩 Modèle Produit

1 Créer le dossier model sous app, puis créer produit.model.ts.

2 Modifier la déclaration de l'attribut produits.

3 Affecter trois produits au tableau.

4 Modifier produits.html.
